Black-Scholes 公式原文

Black-Scholes（含连续股息收益率 δ）欧式期权定价公式：

C = S·e−δT·N(d1) − K·e−rT·N(d2) 欧式看涨期权价格
P = K·e−rT·N(−d2) − S·e−δT·N(−d1) 欧式看跌期权价格

其中：

d1 = ln(S/K) + (r − δ + σ²/2)·Tσ·√T d₁ 计算式
d2 = d1 − σ·√T d₂ 计算式
N(x) = 1√2π · ∫−∞x e−t²/2 dt N(x)：标准正态分布累积分布函数（CDF），即 Φ(x)
N′(x) = 1√2π · e−x²/2 N′(x)：标准正态分布概率密度函数（PDF），即 φ(x)
Γ = e−δT·N′(d1)S·σ·√T ，  Θcall = −S·e−δT·N′(d1)·σ2·√T − rK·e−rT·N(d2) + δS·e−δT·N(d1) ，  V = S·e−δT·N′(d1)·√T Gamma / Theta(看涨) / Vega 公式

Black-Scholes 模型假设：欧式期权、无交易成本、波动率恒定、标的资产价格服从几何布朗运动。
