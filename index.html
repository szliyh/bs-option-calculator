Black-Scholes 公式说明与计算结果

公式原文

C = S·N(d1) − K·e−rT·N(d2) 欧式看涨期权价格
P = K·e−rT·N(−d2) − S·N(−d1) 欧式看跌期权价格（等价于买卖权平价 P = C − S + K·e−rT）
d1 = ln(S/K) + (r + σ²/2)·Tσ·√T d₁ 计算式
d2 = d1 − σ·√T d₂ 计算式
N(x) = 1√2π · ∫−∞x e−t²/2 dt N(x)：标准正态分布累积分布函数（CDF），即 Φ(x)
N′(x) = 1√2π · e−x²/2 N′(x)：标准正态分布概率密度函数（PDF），即 φ(x)

以上为经典 Black-Scholes 公式（δ = 0）。若设置 δ ≠ 0，计算将按含连续股息收益率的完整公式进行：d₁ 分子含 −δT 项，价格与希腊字母含 e−δT 因子。
